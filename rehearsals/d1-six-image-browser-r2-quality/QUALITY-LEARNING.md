# R2 quality repair learning

R1 proved the browser/image path but exhausted four genuine Story 1 attempts without acceptance. No asset was accepted, so R2 does not redo accepted work.

The repeated defects were:
- placeholder/pseudotext-like horizontal marks on blank evidence/document surfaces;
- generic stacked-sheet and floating-panel motifs;
- processing/review geometry that looked decorative rather than causal;
- polished workflow-infographic appearance below the required high-density textbook mechanism benchmark.

R2 changes prompt specificity, not the architecture:
- exposed internal causal substructure in Process;
- explicit multi-fragment evidence lattice with trace binding;
- mechanistic multi-criterion Review gate;
- specific return junction and re-entry point;
- explicit ban on generic sheet stacks, placeholder lines, dashboard panels, and decorative geometry.

The quality threshold is not weakened.
