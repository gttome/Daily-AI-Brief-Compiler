# Promotion Criteria

The Daily Compiler remains a shadow challenger until repeated real editions show:

- zero owner intervention;
- zero Work/Codex/paid API production dependencies;
- six complete stories with exact 2/2/2 allocation;
- exactly one Agent Skills story;
- required media, Watchlist, book mappings, and six accepted images;
- zero accepted-image regeneration;
- deterministic bundle validation PASS;
- live shadow preview verified;
- no Supervisor, Watchdog, lease, worker-pool, or runtime-repair machinery.

One successful run is insufficient for production promotion.
