Summary: Microsoft Foundry’s public-preview optimizer uses recorded agent traces to propose revisions to instructions and tool descriptions, then evaluates candidate variants. It is aimed at prompt agents rather than every Copilot workflow, and Microsoft tells operators to review results before promotion. Because traces may invoke tools, the safe path uses read-only or isolated systems.

Why it matters: Create a frozen trace set with success and failure cases, run proposed changes outside production systems, and require a person to approve both the instruction diff and evaluation result before final promotion.
