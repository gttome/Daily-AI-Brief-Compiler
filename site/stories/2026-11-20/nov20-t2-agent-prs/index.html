Summary: Researchers analyzed 71,677 pull requests attributed to six coding agents. Pooled coauthored changes merged less often than agent-only changes, but removing one dominant agent reversed that pattern, exposing composition effects. Adding context features improved reported merge prediction from 0.774 to 0.832 AUC. The observational study does not establish that any review practice caused acceptance.

Why it matters: Engineering leaders should not compare agent merge rates without agent mix, repository context and attribution rules. Track review depth, requested changes and final disposition separately, then test whether an intervention improves outcomes rather than reading causality into retrospective correlations.
