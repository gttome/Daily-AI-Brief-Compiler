Summary: Cole Medin’s video-editing skill defines a local-first workflow: run environment checks, transcribe media, make forced-alignment cuts, then validate word differences, frame grids, loudness and synchronization before human approval. An optional OpenRouter-assisted mode is separate and sponsored; the reusable core does not require it. The repository is a procedure, not evidence of editing quality.

Why it matters: Communications teams can reuse the skill as an auditable checklist. Start with a short approved clip, preserve the original, inspect transcript and frame changes, test audio sync and loudness, and require a named reviewer before export.
