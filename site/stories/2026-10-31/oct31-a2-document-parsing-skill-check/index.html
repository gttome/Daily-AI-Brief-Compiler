Summary: LlamaIndex published a working draft of the Document Parsing Protocol and a downloadable reference for Claude or ChatGPT. The protocol is version 0.1, so broader interoperability remains unproven.

Why it matters: Knowledge workers can install one reference skill, parse the supplied sample page, verify two exact cells and a preserved negative number, then record corrections before trusting parsed documents in search or agent workflows.
