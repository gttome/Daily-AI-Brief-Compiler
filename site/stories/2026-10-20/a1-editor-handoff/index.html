Summary: GitHub’s tutorial shows how to open a Copilot app session in VS Code while retaining its conversation, code changes and working context. The handoff lets an agent complete broad work remotely before a developer inspects the diff, continues the discussion, edits files and runs local tests. Pushing remains tied to the session’s pull request.

Why it matters: Use session transfer as a review boundary. Confirm the expected branch and worktree, inspect every changed file, rerun project checks and make manual corrections before updating the pull request; preserved context should accelerate review, not substitute for it.
