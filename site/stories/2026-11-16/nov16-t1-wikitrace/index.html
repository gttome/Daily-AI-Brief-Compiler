Summary: WikiTrace introduces an evidence-linked memory system for long-running language-model agents. Instead of storing conclusions alone, it preserves insights, rationales and trajectories, then retrieves them across five agent benchmarks. The authors report gains over prior memory methods and over a same-insights baseline, while identifying and reducing memory-induced performance degradation.

Why it matters: When testing agent memory, retain the source evidence and reasoning path beside each stored insight. Compare against both no-memory and same-insight baselines, then log cases where retrieved memories degrade decisions instead of assuming every retained trace helps.
