**Summary:** GitHub made enterprise open-source license compliance generally available. Repository rulesets can require license checks before merge, annotate newly added dependencies that violate centralized policy and route exception closures to a dedicated enterprise role. Audit events and policy APIs support external records, while a package-check endpoint lets coding agents avoid recommending disallowed dependencies.

**Why it matters:** Treat license policy as a machine-readable tool constraint, not a post-review checklist. Test an allowed package, a prohibited package and an approved exception, then confirm the pull request, audit log and agent recommendation all reflect the same decision.
