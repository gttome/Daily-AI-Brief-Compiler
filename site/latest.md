![Illustration pending for More agents help only after they learn what to share. Planned illustration: Four agents exchange private facts under a shared reward while charts compare success, token use and message patterns against an explicit budget.](https://gttome.github.io/Daily-AI-Brief-Compiler/briefs/images/2026-11-28/illustration-pending.svg?v=fe54b845623b)

**Summary:** A Hugging Face experiment trains four small agents sharing one policy to exchange private numbers. Success increased from 6.6% to 82.3% while generated tokens fell 37.4%, and held-out success reached 26 of 32 tasks. Because one agent lacks the needed information, the experiment cannot show that a swarm beats one capable agent.

**Why it matters:** Before adding agents to a personal workflow, identify information one role uniquely holds, compare the team with a single-agent baseline under the same budget, and keep only coordination that improves a checked outcome.

**Summary:** SayDo tests six vision-language models across 11,480 episodes and eleven household or laboratory hazards, from text questions through simulated robot control. **Why it matters:** For any model that can move equipment, repeat safety tests in the actual control loop, include benign controls and operator pushback, and log when the model recognizes a hazard yet still acts.
