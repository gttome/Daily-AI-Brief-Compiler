Date: November 13, 2026

Topics: Safety evaluation, Measurement design, Reproducible evidence

Open the permanent story page

Evidence: Publisher Authored
Availability: Available

Summary: Anthropic’s safety-evaluation guide argues that deployment claims depend on construct validity, domain expertise, safe test environments, human-validated graders and fully reported uncertainty. It distinguishes observational comparisons from causal tests and shows how configuration changes can shift results. 5. Flawed simulators expose overconfident research agents

Recency fallbackSource article · about 7 min read

Originally published: 16 Nov 2026

Focus: Technical AI Engineering

Date: November 16, 2026

Topics: Scientific agents, Tool mismatch, Calibrated uncertainty

Open the permanent story page

Evidence: Publisher Authored
Availability: Available

Summary: SciResearch-Eval tests agents that design thermal experiments while relying on a simulator that can be under-resolved or physically wrong. Across 2,511 held-out episodes, many models reported narrow but incorrect intervals when physics was missing. Safer experiment design, not simply wider intervals, separated better-calibrated systems, with substantial reasoning-cost tradeoffs.

Why it matters: Agent builders can use this benchmark pattern to test whether a system notices flawed tools, chooses robust experiments and calibrates uncertainty. Record interval coverage, diagnostic behavior and reasoning cost instead of accepting a correct-looking point estimate.

Summary: Microsoft released MAI Code 2 and Code 2 Flash for complex repository work and high-volume routine edits. Its launch reports price-performance advantages across selected coding benchmarks and a blind frontend preference test. Microsoft also says the models are not yet tuned for fundamental science or very long-horizon agents, making workload scope central to evaluation.
