# F2 — Deterministic BUNDLE_READY Compiler Trigger

This disposable feasibility proof tests only the deterministic GitHub half of the Daily Compiler.

A single commit creates a fixture whose compiler state is `BUNDLE_READY`. That push must autonomously cause GitHub Actions to:

1. validate the state and bundle;
2. verify exact 6-story / 2-2-2 / one-Agent-Skills / 2-video / 2-podcast structure;
3. verify the bundle digest;
4. build a deterministic static reader artifact;
5. persist a machine-readable receipt;
6. never call ChatGPT.

The fixture is explicitly synthetic and is not a Daily AI Brief edition candidate.
