- exactly six expected assets;
- story mapping;

Then use the protected repository path: PR, exact-head CI, bounded repair of ingest-related failures, protected merge, deployment and exact live-byte verification.

If transport/Git/CI/deploy fails, preserve and reuse the same six accepted assets and manifest. Never return to image generation.
