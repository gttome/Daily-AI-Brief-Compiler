D1 IMAGE STUDIO — FRESH CLOUD TASK

This task is the sole subjective visual-quality gate for six Daily AI Brief reader images.

INPUTS
- six locked story image specifications;
- the canonical Perfect Image standard;
- exact visible-text allowlists;
- six-image differentiation assignments.

CONTEXT ISOLATION
Use only those inputs. Do not inspect GitHub, repository state, CI, publication state, run history, Dot history, Work instructions, prior Brief images, or unrelated orchestration material.

CREATE
Generate six distinct native ChatGPT images, one story at a time. Default target is 1200x630 or a lossless normalization-compatible landscape native asset.

QUALITY
For every candidate enforce premium textbook/editorial publishing quality, high information density, mechanism-rich explanation, 8+ meaningful visual components, strong hierarchy, visual depth, story specificity, exact allowlisted visible text only, no logos/brands, no photos, no people/humanoids/avatars, no pseudo-text, no sparse/basic boxes-only fallback, and no unsupported details.

If a candidate is weak, visually generic, sparse, text-contaminated or structurally wrong, reject it here and generate a new candidate. Maximum four genuine visual-quality attempts per story.

SET REVIEW
Before final acceptance require six unique compositions and byte streams with strong cross-set differentiation. Do not accept six minor template variants.

OUTPUT
Return six individual accepted cloud image assets, not a ZIP, plus daily-compiler-d1-image-acceptance-manifest-v1. The manifest must bind story ID, cloud asset ID, filename, width, height, format, bytes, SHA-256, composition signature, visible-text allowlist, accepted attempt, PASS and accepted_locked. Do not include repository names, branches, Git paths, CI instructions, publication state, or Work instructions in the Studio output manifest.

Once the manifest is emitted, those exact asset bytes are immutable. Do not perform GitHub work.
